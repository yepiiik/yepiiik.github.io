Web platform for searching and comparing edge-tech AI models

Database architecting and integrating Next.js server with REST API. Deployment to VPS in Kubernetes.

Tech Stack

  • TypeScript

  • Tailwind CSS
  • Github Actions
  • Docker
  • Nginx
  • Kubernetes

About the Project

The main challenge was designing a scalable database schema to handle complex relationships between AI models, their features, and user interactions. I implemented a robust PostgreSQL schema with efficient indexing and optimized queries to ensure fast response times. The deployment process involved containerizing the application with Docker and orchestrating it using Kubernetes on a self-managed VPS, ensuring high availability and scalability.
